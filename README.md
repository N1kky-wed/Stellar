# Stellar AI Operating System

A persistent, stateful AI operating system for total autonomous agency across infrastructure, research, and design. Orchestrate Docker clusters, clone Git repos, and perform deep research with YouTube intelligence.

## Core Pillars

### 1. Repo Control (Industrial Environment)
The heavy-lifting environment for industrial-grade projects. Deploy multi-file React, Node.js, Go, or Python applications with persistence. Repo Control automatically snapshots your code state, ensuring your progress is never lost across container restarts.

### 2. The Lab (Rapid Prototyping)
A zero-latency sandbox for data science, security testing, and script execution. Files from your chat automatically sync to `/lab`, allowing for immediate analysis or transformation using standard Linux tools and Python.

### 3. Multimedia Intel
*   **YouTube Intelligence:** Perform deep analysis of video content, extracting transcripts and technical insights.
*   **Imagen 3:** Generate professional high-fidelity assets and SVGs natively.
*   **Presentations:** Generate and refine multi-slide professional PowerPoint presentations autonomously.

## System Guidelines

### Infrastructure
*   **Docker Orchestration:** Every workspace is a hardened container with isolated networking.
*   **Persistence:** Code edits in Repo Control are preserved via automated SQLite snapshots.
*   **Managed File System:** Securely move files across environments (Chat ↔ Lab ↔ Repo).

### Autonomous Logic
Stellar is designed for **total agency**. It identifies technical failures, analyzes logs, and applies patches without user intervention. It operates as a root-level administrator within its sandboxes to deliver results, not just text.
